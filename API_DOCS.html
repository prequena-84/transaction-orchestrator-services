Transaction Orchestrator Service (BFF / Saga)

Documentación técnica de los endpoints del Orquestador.

1. Módulo: Transacciones (Saga Orquestación)

Endpoint Propósito Params / Query Body (Request) Respuesta (Response)
POST /api/v1/transactions Inicia una Saga de Transferencia N/A { "source_account": "UUID", "target_account": "UUID", "amount": 100.50, "currency": "USD" } HTTP 201: Objeto TransactionEntity (Estado Inicial: PENDING)
GET /api/v1/transactions/:transaction_id Consultar estado de la transacción (Polling) transaction_id (UUID) en URL N/A HTTP 200: Objeto TransactionEntity (Estado actual)
PATCH /api/v1/transactions/:transaction_id/state Actualizar estado manual (Webhooks internos) transaction_id (UUID) en URL { "saga_state": "COMPLETED" | "FAILED" } HTTP 200: Objeto TransactionEntity actualizado
